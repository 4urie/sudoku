# Sudoku Studio

A responsive, browser based Sudoku prototype. Open `index.html` in a browser to play. No installation or account is required.

## Playing instructions

Fill the empty squares with digits 1–9. Every row, column, and bold 3 × 3 box must contain each digit exactly once. Prefilled squares cannot be edited.

1. Choose Easy, Medium, or Hard, then select **New game**.
2. Click or tap an empty square and select a digit from the number pad. On a keyboard, use digits 1–9 and arrow keys to move.
3. Turn on **Notes** to record possible digits. Use **Erase** or Backspace to clear a square.
4. Use **Hint** to reveal one answer, or **Check** to highlight incorrect entries.
5. Fill the board correctly to finish the puzzle. The timer stops when it is solved.

Select **Take a tour** beside the timer for a moving pointer walkthrough of the controls. The tour opens automatically on a first visit if you have not begun interacting, and can be skipped with **Esc** or the close button.

Each generated puzzle has one solution. Difficulty is based on the number of starting clues; it does not measure solving technique.
